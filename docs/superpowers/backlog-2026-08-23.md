## Guardrails (do not regress)

- Plan entitlements stay config-driven (no `$plan->name === 'Pro'`, no hardcoded limits; admin plan config is source of truth).
- Order settlement fields immutable after creation; future plan changes affect only future sales.
- Domain gating (`LinkeablePublicPolicy`) is intentional security — tests use `config('app.url')` hosts.
- Settings-mutating migrations/seeders must invalidate `settings.public` (deploy.sh `cache:clear` now backstops this).
- Deploys run migrations only — anything needing data backfill ships as a migration.
