Every link you share through [Website Name] starts as a short link. This article walks through creating your very first one.

Create the link

  1. Open your dashboard and click Create new.
  2. Paste the long URL you want to shorten.
  3. Optionally edit the back-half so the short URL reads the way you want, for example your.name/hello.
  4. Click Shorten.

Your new link is ready immediately and can be shared right away.

What to do next

  • Organize the link into a folder so it is easy to find later.
  • Open the link's analytics to watch clicks arrive in real time.
  • Add a tracking pixel if you plan to run ads against this traffic.

That is all it takes — you can create as many links as your plan allows.
